# Quantum Sound 🎧

A modern, responsive 3D landing page for gaming headphones featuring glassmorphism and smooth CSS animations.

## 🚀 Live Demo
[Click here to view the Live Demo](https://asal-heidary.github.io/QuantumSound/)

## ✨ Features
- **3D & Glassmorphism UI:** Modern visual effects built purely with CSS.
- **Fully Responsive:** Smooth layout adapted for mobile, tablet, and desktop screens.
- **Clean Code:** Structured HTML5 & modular CSS3.

## 🛠️ Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, Animations, Glassmorphism)
